Multi-Agent Reinforcement Learning trains collaborating policies from task rewards. [Multi-Agent REINFORCE]({{< relref "docs/marl/multi-agent-reinforce" >}}) describes critic-free updates, while [Multi-Agent Actor-Critic]({{< relref "docs/marl/multi-agent-actor-critic" >}}) describes value-based training.
