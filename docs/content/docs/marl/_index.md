Multi-Agent Reinforcement Learning trains collaborating policies from task rewards. [Multi-Agent REINFORCE]({{< relref "docs/marl/multi-agent-reinforce" >}}) describes critic-free updates, [Multi-Agent Actor-Critic]({{< relref "docs/marl/multi-agent-actor-critic" >}}) describes value-based training, [Multi-LLM PbRL]({{< relref "docs/marl/multi-llm-pbrl" >}}) describes training from preferences between joint responses, and [Multi-Turn Interaction]({{< relref "docs/marl/multi-turn-interaction" >}}) describes training across multiple turns with environment feedback.
